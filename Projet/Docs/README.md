# M FOR MUMS - Documentation

Bienvenue dans la documentation du projet M FOR MUMS, une plateforme dédiée aux futures mamans.

## 📋 Aperçu

M FOR MUMS est une application web qui accompagne les futures mamans pendant leur grossesse avec des conseils personnalisés, un suivi de grossesse et une communauté d'entraide.

## 🚀 Démarrage rapide

```bash
# Cloner le dépôt
git clone [URL_DU_DEPOT]

# Installer les dépendances
npm install

# Configurer l'environnement
cp .env.example .env

# Démarrer l'application
npm start
```
